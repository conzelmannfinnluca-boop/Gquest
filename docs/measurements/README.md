# Messergebnisse

Hier landen **ausgewertete** Performancedaten je Gerät, eine Datei pro Gerät
(`quest3.md`, `quest3s.md`), erzeugt nach `docs/PERF_PROTOCOL.md`.

Der Ordner ist bis zur ersten Messreihe leer. Das ist Absicht: eine Datei hier ist ein
Nachweis, und ein Nachweis entsteht erst durch 9 gültige Läufe, nicht durch das Anlegen
der Datei.

Was hier **nicht** hineingehört: Rohdaten (`runs/*.csv`), Screenshots des HUD oder
gefühlte Eindrücke. Rohdaten bleiben lokal; in der Zusammenfassung steht nur die
ausgewertete Tabelle mit Verweis auf die Rohdateinamen.

Solange dieser Ordner leer ist, bleibt `Performance-Messung auf Quest 3` in
`PROJECT_STATUS.md` auf **NOT TESTED** und Quest 3S auf **NOT TESTED**.
