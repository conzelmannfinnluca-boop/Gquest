# Repository und Veröffentlichung

GitHub: https://github.com/conzelmannfinnluca-boop/Gquest

Das Repository ist privat. Es enthält die bereinigten eigenen Integrationsquellen, Tests und Dokumentation. Spieldateien, Engine-Bibliotheken, VR-Modelle, Texturen, APKs, Zugangsdaten und Signierschlüssel werden nicht hochgeladen.

Für einen Build werden die in BUILD.md beschriebenen separaten Abhängigkeiten benötigt. Vor einer öffentlichen Freigabe müssen externe Referenzdaten und ein reproduzierbarer Build geprüft werden.

Der eigene Integrationscode steht unter der MIT-Lizenz (siehe LICENSE). Die Herkunft aller externen Komponenten und die Kennzeichnungspflicht für VRMod-Ableitungen sind in THIRD_PARTY_NOTICES.md festgehalten. Eine Store-Veröffentlichung ist damit nicht automatisch zulässig: sie hängt an der geschlossenen GDroid-Basis und den separat erforderlichen Retail-Inhalten und ist vor einem Release gesondert zu klären.
