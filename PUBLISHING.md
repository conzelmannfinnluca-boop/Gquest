# Repository und Veröffentlichung

GitHub: https://github.com/conzelmannfinnluca-boop/Gquest

Das Repository ist privat. Es enthält die bereinigten eigenen Integrationsquellen, Tests und Dokumentation. Spieldateien, Engine-Bibliotheken, VR-Modelle, Texturen, APKs, Zugangsdaten und Signierschlüssel werden nicht hochgeladen.

Für einen Build werden die in BUILD.md beschriebenen separaten Abhängigkeiten benötigt. Vor einer öffentlichen Freigabe müssen Lizenz, externe Referenzdaten und ein reproduzierbarer Build geprüft werden. Derzeit ist keine Weiterverwendungslizenz für die eigenen Anpassungen festgelegt.
